오리지널: 꼬마기 10분 · 전사기 6시간 · 기사기 24시간 · 영웅기 36시간 · 전설기 48시간 (잠든 동안엔 멈춰). 빠른 진행: 한 번 앉은 자리에서 끝까지 볼 수 있는 속도.

시간 배속

시간 배속은 성장·배고픔 타이머를 빠르게 돌려. 진화를 빨리 보고 싶을 때 써 봐.

링커 색

📲 사파리 아래쪽 공유 버튼 → 홈 화면에 추가를 누르면 주소창 없이 앱처럼 쓸 수 있어. (홈 화면 앱은 사파리와 저장 공간이 따로라서, 처음부터 시작돼.)

    버튼: 옆면 A 고르기 · B 결정 · C 취소/돌아가기. A+B 동시: 알 선택. A+C 동시: 사운드 켜기/끄기. 아이콘을 직접 눌러도 돼. 키보드는 Z / X / C.

    상태: A·B로 넘겨 봐. 이름 → 나이·체중 → 배고픔 → 근력 → 노력 → 체력 → 싱글 승률 → 태그 승률.
    밥: 고기는 배고픔 +1 (가득 차면 싫어싫어). 프로틴은 근력 +1, 4개마다 체력 +1. 근력이 가득한데 계속 주면 탈이 나.
    훈련: 「!」가 뜨면 A 연타! 벽을 조금이라도 부숴야 근력이 올라. 훈련 4회마다 노력 하트 +1 (진화하면 0).
    배틀: 싱글(HP 10) 또는 태그(HP 30, 앨범 속 동료와). 「!」가 뜨면 3초 동안 A 연타 → 서로 기술을 주고받아. 6턴 안에 HP를 0으로 만들거나 더 많이 남기면 승리. 이길수록 상대가 강해지고, 「계속」이나 「처음부터」를 고를 수 있어. 배틀 1번에 체력 1.
    태그는 눈금을 A나 B로 멈춘 다음 연타. 맞으면 동료와 교대해. 눈금과 연타가 맞아떨어지면 크리티컬!
    LINK: 연타와 응원으로 게이지가 차면 B로 공명 진화나 필살기. 배틀이 시작되면 화면이 컬러로 바뀌어.
    불: WAKE로 깨우기, SLEEP으로 재우기(낮엔 낮잠). 잘 땐 배고픔·근력이 줄지 않고 진화 시간도 멈춰. 체력이 회복돼.
    치료: 해골 마크가 사라질 때까지. 다친 채 오래 두면 데이터가 흩어져 버려.
    진화: 꼬마기까지 케어 실수 0~2회 / 3회 이상으로 전사기가 갈리고, 전사기의 훈련량과 실수로 기사기 5갈래. 영웅기는 15전 12승, 전설기는 이 단계 케어 실수 2회 이하에서 진화. 진화표는 메뉴에서.
    특수 알: NPC 배틀 50승이면 폭풍 알, 100승이면 월식 알. 파트너 5종을 획득하면 별 알, 25종을 획득하면 혜성 알. 합체: 전설기끼리 태그 배틀로 함께 이기면.

    화면을 길게 누르면 파트너가 밖으로 나와. 문질러 쓰다듬어 줘. 배틀 중엔 폰을 흔들어도 응원이 돼(브라우저에서 직접 열었을 때).
