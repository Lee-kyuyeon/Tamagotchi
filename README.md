# 코드 링커 (CODE·LINKER)

하늘에서 떨어진 기계, 그 안에서 깨어난 파트너. 애니메이션 속 "선택받은 아이"가 된 기분으로 키우는 휴대용 파트너 기기 게임입니다.
빌드 없이 `index.html` 하나로 동작합니다. GitHub Pages로 열면 아이폰 사파리에서 **공유 → 홈 화면에 추가**로 앱처럼 설치할 수 있어요(오프라인에서도 실행). 아이폰 사파리에서 처음 열면 홈 화면 추가 안내가 나와요. **지금은 사파리에서 시작**을 누르면 기존 오프닝으로 넘어가고, 안내는 설정에서 다시 열 수 있어요. 홈 화면 아이콘으로 열면 오프닝이 바로 시작돼요. 진행은 실행한 브라우저나 홈 화면 앱에 자동 저장됩니다.

## 화면
평소에는 64×48 흑백 도트 LCD(픽셀 그림자·잔상 효과), 배틀이 시작되면 화면이 위에서부터 컬러로 바뀝니다. 파트너는 숨쉬기·깜빡임·기쁨·먹기·화남·잠 표정 프레임으로 움직여요.

## 조작
- 본체 오른쪽 옆면 버튼 **A** 아이콘 선택 / 배틀 중 **연타로 응원** · **B** 결정 · **C** 취소 (키보드 Z / X / C)
- 화면 위아래 아이콘을 직접 눌러도 됩니다.

## 주인공 연출
- 오프닝: "그 세계가 너를 선택했어" → 하늘에서 떨어지는 링커 → 테이머 이름·기기 색 선택
- 진화 컷신: 광선·실루엣 교차·플래시·이름 외치기 + 팡파르와 진동
- 배틀: WARNING 경보, 응원으로 LINK 게이지를 채워 **공명 진화**(배틀 동안 한 단계 위로) 또는 **필살기**
- 이정표마다 애니메이션처럼 **에피소드 타이틀 카드**가 뜨고 메뉴에서 다시 볼 수 있음
- 링커를 켜 두면 무작위로 적 신호가 울림

## 폰이라서 가능한 것
- **오프닝 「그날 밤」**: 처음 켠 실제 날짜·시각으로 시작. 방 안 모니터를 붉은 숫자가 뒤덮고, 화면이 부풀며 알이 튀어나와요(밤·해 질 녘·낮 연출이 달라요).
- **손 온기로 부화**: 알이 부르면 화면을 눌러 손가락으로 감싸거나 문질러 깨워요. 심장박동이 빨라지며 금이 갑니다.
- **화면 돌파**: 진화·공명 진화·필살기 때 파트너가 LCD 유리를 깨고 풀컬러로 튀어나와요. 화면을 길게 누르면 밖으로 나와 쓰다듬을 수 있어요.
- **흔들어 응원**: 배틀 중 폰을 흔들면 LINK 게이지가 차요. claude.ai 안에서는 센서가 막혀 있어 GitHub Pages 등에서 직접 열었을 때만 동작합니다.

## 설명서 흐름
- **상태 8페이지**: 이름 → 나이·체중 → 배고픔 → 근력 → 노력(훈련 4회마다 하트, 진화하면 0) → 체력 → 싱글 승률 → 태그 승률
- **밥**: 고기(배고픔 +1, 가득 차면 싫어싫어) · 프로틴(근력 +1, 4개마다 체력 +1, 과하면 탈)
- **훈련**: 「!」가 뜨면 A 연타 → 벽을 부숴야 근력 +1, C로 중단
- **배틀**: 싱글(HP 10) / 태그(HP 30, 앨범 속 동료와, 맞으면 교대). 3초 연타 → 자동 공방, 6턴. 이길수록 상대가 강해지고 「계속/처음부터」 선택. 배틀 1회에 체력 1
- **불**: WAKE(15분 깨우기) / SLEEP(밤엔 이불, 낮엔 3시간 낮잠). 자는 동안엔 배고픔·근력이 줄지 않고 진화 시간도 멈춤
- **치료**: 해골 마크가 사라질 때까지. 오래 방치하면 데이터가 흩어져 앨범으로
- **앨범** · **A+B 동시**: 알 선택 · **A+C 동시**: 사운드

## 진화표

기본 알은 불꽃·물결·새순·꽃잎·수정 5종입니다. 꼬마기까지 케어 실수 0~2회 또는 3회 이상으로 전사기가 갈립니다. 전사기는 훈련량과 케어 실수에 따라 기사기 5갈래로 진화합니다.

기본 진행에서 새싹기 → 꼬마기는 10분, 꼬마기 → 전사기는 6시간, 전사기 → 기사기는 24시간입니다. 기사기 → 영웅기는 36시간과 해당 단계의 배틀 15전 12승, 영웅기 → 전설기는 48시간과 해당 단계 케어 실수 0~2회가 필요합니다. 빠른 진행에서는 진화 대기 시간이 짧아집니다.

- NPC 배틀 누적 50승에 폭풍 알, 100승에 월식 알을 해금합니다. 싱글과 태그 승리를 모두 셉니다.
- 도감에 육성으로 획득한 파트너가 5종이면 별 알, 25종이면 혜성 알을 해금합니다. 배틀에서 만난 상대는 도감에 표시되며 획득 종수에는 포함되지 않습니다.
- 전설기끼리 태그 배틀로 함께 이기면 합체할 수 있습니다.

모든 몬스터·이름·대사·음악은 이 프로젝트를 위해 새로 만든 오리지널입니다.

## 글리치와 통신하기

전사기 이후 배틀 메뉴의 **글리치 신호**를 열면 싱글 라이벌전에 출격할 수 있습니다. **기기 내 모델 받기**를 누르면 약 440MB의 Qwen2.5-0.5B-Instruct 양자화 모델과 브라우저 실행 파일을 내려받습니다. 모델을 준비한 뒤에는 출격 전에 자유 입력 한 줄을 보낼 수 있습니다. 글리치는 지난 대화와 라이벌전 기록을 참고하며, 전투가 끝나면 **글리치의 전투 기록**에서 답을 확인할 수 있습니다.

추론은 브라우저의 Web Worker에서 WebAssembly로 실행합니다. 대사와 전투 기록은 게임의 로컬 저장 공간에 저장하며, 텍스트를 처리하는 외부 서버는 없습니다. HTTPS의 홈 화면 앱에서 모델과 실행 파일을 내려받아 보관한 경우 오프라인 대화를 시도할 수 있습니다. 성능이나 저장 공간은 기기에 따라 다릅니다. 모델을 준비하지 않았거나 응답에 실패해도 바로 출격할 수 있고 기본 전투 후 대사가 표시됩니다.

## 파트너가 남긴 흔적

파트너가 배부를 때 고기의 마지막 한 입을 LCD 왼쪽 구석에 남겨 둘 수 있습니다. 구석을 짧게 탭하면 파트너가 먹이를 가리거나, 이미 먹고 남은 부스러기를 살펴볼 수 있습니다. 앱을 닫았다가 열어도 실제 경과 시간에 맞는 흔적이 보입니다. 숨겨 둔 먹이는 별도의 보상이나 능력치 변화를 주지 않습니다.

글리치전 승·패·무는 라이벌 전투 기록에 별도로 표시되며, 일반 배틀의 진화 조건과 특수 알 해금에는 일반 전적이 쓰입니다. 이전 버전에서 이미 쌓인 일반 전적은 그대로 이어집니다. 시간 배속은 성장과 진화에 적용되며 먹이, 위생, 체력 회복과 케어 실수는 실제 시간으로 처리됩니다.
