# 코드 링커 (CODE·LINKER)

하늘에서 떨어진 기계, 그 안에서 깨어난 파트너. 애니메이션 속 "선택받은 아이"가 된 기분으로 키우는 휴대용 파트너 기기 게임입니다.
빌드 없이 `index.html` 하나로 동작합니다. 브라우저로 열면 바로 시작돼요(모바일 권장, 진행은 브라우저에 자동 저장).

## 화면
평소에는 64×48 흑백 도트 LCD(픽셀 그림자·잔상 효과), 배틀이 시작되면 화면이 위에서부터 컬러로 바뀝니다. 파트너는 숨쉬기·깜빡임·기쁨·먹기·화남·잠 표정 프레임으로 움직여요.

## 조작
- 본체 오른쪽 옆면 버튼 **A** 아이콘 선택 / 배틀 중 **연타로 응원** · **B** 결정 · **C** 취소 (키보드 Z / X / C)
- 화면 위아래 아이콘을 직접 눌러도 됩니다.

## 주인공 연출
- 오프닝: "그 세계가 너를 선택했어" → 하늘에서 떨어지는 링커 → 테이머 이름·기기 색 선택
- 진화 컷신: 광선·실루엣 교차·플래시·이름 외치기 + 팡파르와 진동
- 배틀: WARNING 경보, 응원으로 LINK 게이지를 채워 **공명 진화**(배틀 동안 한 단계 위로) 또는 **필살기**
- 이정표마다 애니메이션처럼 **에피소드 타이틀 카드**가 뜨고 메뉴에서 다시 볼 수 있음
- 링커를 켜 두면 무작위로 적 신호가 울림

## 성장 루트
알 → 모찌 → 꼬리롱 → (훈련이 많으면) 피로 → 플레이드 → 인페르곤 → 솔라리온
　　　　　　　　　　　 (교감이 많으면) 루포 → 볼트팽 → 썬더가르 → 아스트라이온

| 단계 | 조건 |
|---|---|
| 기사기 | 전사기에서 15분 + 배틀 3승 |
| 영웅기 | 기사기에서 30분 + 10승 + 링크 50 |
| 전설기 | 15승 + 링크 80에서 배틀 중 LINK MAX → B (최종 공명 진화) |

메뉴 → 설정의 **시간 배속(x10, x60)**으로 성장을 빠르게 볼 수 있습니다. 0시~7시엔 파트너가 잠들어요(교감으로 잠깐 깨울 수 있음).

모든 몬스터·이름·대사·음악은 이 프로젝트를 위해 새로 만든 오리지널입니다.
